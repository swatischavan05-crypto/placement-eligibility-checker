
🎓 Placement Eligibility Checker

A smart and responsive web application that helps students check their placement eligibility for multiple companies based on academic performance, branch, backlogs, and graduation details.

🚀 Features
👤 Student profile management
📊 CGPA eligibility checking
📝 10th & 12th/Diploma percentage checking
❌ Backlog verification
🎓 Branch eligibility checking
🏢 25+ company eligibility criteria
🔍 Company search
✅ Eligible / ❌ Not Eligible filtering
📋 Shows reasons for ineligibility
📈 Eligibility percentage
🌙 Dark mode
💾 LocalStorage profile saving
📱 Responsive design
🎯 Apply Now demo functionality
🛠️ Technologies Used
HTML5
CSS3
JavaScript
LocalStorage
Responsive Web Design
▶️ How to Run
Download or clone this repository.
Open index.html.
Open it in any modern web browser.
Enter your academic details.
Click Check My Eligibility.
View eligible companies and placement opportunities.
